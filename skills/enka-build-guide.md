# Enka 配装诊断与优化

用户想让自己某个角色的配装更优时，按下面流程做；**不要只看角色名就凭印象给一套通用配装**。

## 1. 先拿数据

- 需要 **游戏 + UID + 角色名**。缺 UID 就问，不要猜；绝区零国服 UID 是 8 位。
- 不知道展柜里有哪些角色：先 `enka_genshin` / `enka_hsr` / `enka_zzz`。
- 再 `enka_build`：`uid`、`game`（genshin/hsr/zzz）、`character`（角色名或 ID）。
- 工具会返回逐件主副词条、套装、武器、命座/星魂/影画，以及副词条合计和双暴分。

## 2. 再补版本信息（可选）

角色刚上线/刚改版、或用户问“当前版本”时，用 `miyoushe_search` 查最新攻略，避免拿旧版本推荐。工具数据是玩家当前展柜，攻略是版本环境，两者要分开引用。

## 3. 分析顺序

1. **套装**：当前是 4 件套还是 2+2？和角色主流定位是否匹配；不匹配时先定目标套装，再谈词条。
2. **主词条**：逐部位对比主流选择（如输出角色通常攻击/属性伤/双暴；辅助看充能/生命/防御/精通）。错得明显的部位优先换。
3. **副词条**：看双暴分、有效词条数与速度/充能/命中/击破等阈值；不要只报双暴分，充能不够会断循环。
4. **武器**：当前武器是否适配；有更优下位替代时说明精炼与获取成本，不强推五星。
5. **保留件**：明确指出哪些件已经很好、不用换，避免让用户白刷。

## 4. 输出格式

先给一句结论（当前配装大概处于什么水平、最该改什么），再给：

| 部位 | 当前 | 建议 | 原因 |
| --- | --- | --- | --- |

最后给：

- **替换优先级**：先换哪件、为什么；
- **目标面板**：暴击/暴伤/充能/速度等合理区间（给范围，不装精确）；
- **刷取建议**：哪个本/哪套，是否值得继续赌词条；
- **保留**：哪些件继续用。

## 边界

- 只能看到**公开展柜**；角色未展示、展柜为空时如实说明，不要编。
- 不知道队伍/玩法（主C/副C/辅助、单通/深渊/日常）时，先问一句；不同定位的最优配装不同。
- 不要声称算出精确伤害；没有伤害计算器时只做词条与套装层面的比较。
- 用户只问“看看我的角色”时，先给展柜摘要，不必主动展开整套配装建议。
