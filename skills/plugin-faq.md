当用户反馈**本插件自身的异常/故障/配置问题**（不是普通问答）时，用本说明书按「现象 → 原因 → 处理」排查。先取证据、再给结论，别臆测。

## 0. 通用排查入口（先做这三件）

1. **拿现场证据**：让用户发 `#上报错误 <问题描述>`，会把最近会话日志打包给主人；或让主人看控制台与 `data/logs/`、`data/humanize-logs/`。
2. **配置来源**：用户配置在插件目录 `config/config.yaml`；默认值在 `config/default_config/`。**改了配置若未热加载，发 `#agents重载`**。模型厂商/模型在 Web 面板「厂商配置」「模型列表」维护，`agent.providerId/modelId` 是它们的解析镜像——直接改 `agent.apiKey/model` 会在下次加载被覆盖。
3. **确认版本**：`#agents` 面板或 `package.json` 的 `version`。下列「已修复」条目指对应版本起生效；**生产需把仓库同步部署到实际运行目录**（如 `/root/Yunzai/plugins/agents-plugin`）后重启/重载。

## 1. 启动 / 模型接入

- **报「未选定可用的基础模型 / agent.apiKey 为空」**：没在「厂商配置」填 baseURL+API Key 并挂到「模型列表」，再到「基础/模型」选中。去 Web 面板补齐。
- **`[provider] 请求失败（APIError/net），共 1 次尝试后放弃`**：多为**调用方主动中止**（如 humanize 规划被新一轮取代、超时）或网络/代理不通，不是必崩。看日志消息：
  - 含 `aborted by caller` → 预期中止（可忽略）；
  - 连接类（超时/DNS/ECONN）→ 该端点网络不通，给 `agent.proxy` 配代理或换 baseURL。
  - `APIError/400/401/402` → 参数/鉴权/额度问题，按消息修配置（402 多为余额/额度）。
- **工具调用变成了正文（用户看到 `<tool_calls><invoke …>` 之类文本）**：模型/通道把工具调用内联进了 `content`。**v1.0.4 起**已自动解析回真实调用并从正文剥离；升级并重载即可。若仍见，请 `#上报错误`。
- **回复里混入思考内容 / 空回复**：部分模型把思考内联（` thinking`）或思考吃光 `max_tokens`。插件已剥离内联思考；空正文会进入确定性收尾。给该模型在「模型列表」关思考（`thinking: off`）或提高 `maxTokens`。

## 2. 图片识别

- **「图片识别返回空 / 视觉模型可能不支持图片输入」**：
  - 最常见原因：**视觉模型默认开思考**，`agent.vision.maxTokens`（默认 1024）被推理吃光 → 正文为空。**v1.0.2 起**视觉子模型思考默认关闭；仍空则提高 `agent.vision.maxTokens` 或换非思考视觉模型。
  - 次因：`agent.vision.model` 本身是纯文本模型，或通道未透传图片。核对模型是否多模态（如 `mimo-v2.5`/`*-vl`/`*-omni`）。
- **`inline image declared media type does not match its content`**：声明的图片类型与字节不符（扩展名谎报）。**v1.0.1 起**已按魔数（字节）判定并纠正；AVIF/HEIC 等不受支持的格式会降级为文字说明而非报错。
- **切模型/回退后报 `unknown variant 'image'`（或 image_url/file）**：跨协议会话历史里的内容块形状与新端点不符。**v1.0.0 起**发送前统一按目标协议归一。升级重载。
- **主模型无视觉**：需配 `agent.vision.enable: true` + `agent.vision.model`（支持视觉的模型）。未配时图片会被判为「盲图」并如实告知用户，不会臆测。

## 3. 视频识别

- **视频完全没被识别**：**v1.0.2 起**纯视频消息（无图片）也会触发视觉子模型；主模型有视觉时图片保留原生、仅视频转文本。
- **视频取不到字节**：NapCat 对视频只用 `get_file`（不是 `get_image`），**v1.0.2 起**已修正；常见视频段带直链，缺失时走 `get_file`。
- **视频格式**：已支持 mp4/webm/mkv/mov/avi/flv/mpeg/3gp 等魔数识别。视觉视频走 OpenAI 兼容 `video_url`（如 `mimo` 系 omni），**仅 openai 协议**且模型声明视频能力（`media.caps.video`，`mimo.*omni` 内置）；其它协议/模型会跳过并降级文字。
- **视频超 8MB**：默认 `agent.media.maxFileBytes` 限制，超限不送识别，降级为文字说明。

## 4. 联网搜索无结果

- **现象**：`web_search` 大概率返回「无搜索结果」。
- **原因**：内置 SearXNG 实例的通用引擎被墙/返回 0 结果；且历史上**空结果不回退**、搜索**不读代理**。
- **v1.0.3 起已修**：某源「可用但 0 结果」会自动回退下一源；DDG 走 lite+html 双端点；搜索 fetcher 会使用 `agent.proxy`（或环境 `HTTP(S)_PROXY`，本地地址直连）。
- **仍无结果**：给 `agent.proxy` 配代理（让 DDG 生效），或修好 SearXNG 实例的出网/引擎，或在「搜索」配置填 Tavily/Exa/Perplexity/Brave 任一 API Key。

## 5. 合并转发失败

- **报「未知的消息类型：undefined」**：`send_forward_msg` 的节点必须是 `{type:'node', data:{content,user_id,nickname}}`；**v1.0.2 起**工具会自动把 `{uin,name,content}` 规范成该形状。升级重载。
- 图片节点用 `{type:'image', data:{file:'<url 或 base64://…>'}}`；纯文本可直接给字符串。

## 6. `#上报错误` 相关

- **v1.0.3 起**：发送失败不再静默——会在控制台打印错误日志，并在群聊反馈「❌ 上报失败 / ⚠️ 部分失败」；文本与日志文件分开发送，文件失败不影响文本送达。`agent.masters` 里的 QQ 号写成数字/字符串/带空格都兼容。
- 报「未配置 agent.masters」：在配置里补主人 QQ（数组）。
- 找不到日志：该用户从未触发过 AI，或 `agent.devLog.enable: false`。

## 7. Web 管理面板 / 登录

- **取访问地址**：主人私聊发 `#agents登录`，会**分两条**返回 `🌐 公网地址` 与 `💻 本地地址(127.0.0.1)`；群聊里发会被要求去私聊。
- **本地地址固定**：服务端监听 `0.0.0.0`（同时覆盖公网与本地回环），本地 `http://127.0.0.1:<port>/?token=…` 始终可用、无需配置。
- **端口被占用**：改 `agent.webApi.port` 后 `#agents重载`。
- **打不开**：确认 `agent.webApi.enable: true`；云服务器安全组/防火墙放行端口；公网走 NAT 时优先用本地地址或配 `publicUrl`。
- **token 失效**：24h 过期或进程重启，重新 `#agents登录`。

## 8. 权限 / 工具被拒

- **`tool denied ... 角色 admin 低于 system 所需等级`**：该工具要求的角色等级高于当前用户。用 `agent` 的权限/角色配置调整，或由主人操作。
- **需确认的工具**：高危工具（如部分写操作）走 `#确认 <id>` / `#拒绝 <id>`；主人可开 `agent.masterSkipConfirm`。

## 9. 定时任务 / 提醒

- **一次性提醒**用 `reminder_set`；**周期任务**用 `schedule_task`（`when` 自然语言周期，如"每2小时"）。周期任务需管理员权限。
- 到点没触发：确认调度服务在跑、`selfId` 正确、任务未过期/未取消（`#定时任务列表`）。

## 10. 其它常见配置点

- **改配置不生效**：改 `config/config.yaml` 后多数热加载；模型/provider 结构变化建议 `#agents重载`。
- **多模态总开关**：`agent.media.enable: false` 关闭图片/文件收集（纯文本处理）。
- **人设/系统提示**：`#人设` 系列命令；人设只覆盖身份层，不覆盖工具与安全约束。
- **上下文太长/变慢**：调 `agent.contextWindow`（token 高低水位压缩）与 `maxTurns`。

## 11. 无法自行解决时

1. 让用户发 `#上报错误 <描述>` 收集日志；
2. 引导到官方 QQ 群 **960179589** @群主，附问题描述；
3. 提示同步升级到最新版本（很多问题在 1.0.1–1.1.0 已修复），生产目录需实际更新后重载。

原则：**先分清「框架支持」与「运行时已配置」，再给可执行出路**；不确定就取日志、别猜。
