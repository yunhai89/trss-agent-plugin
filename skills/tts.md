# 语音合成（TTS / IndexTTS 2.5）

**自动语音（默认开）**：`agent.tts.autoReply` 开启时，机器人**每条最终回复都会自动追加一条语音**（文字/图片照常发送；合成内容 = 最终回复剥除 markdown/代码/链接/表格/emoji 后的正文，超长按句截断）。此路径无需你调用任何工具。

**高清语音（默认开）**：`agent.tts.hdVoice` 开启时，发送前自动做响度标准化 + 清晰度补偿（修 TTS 输出偏轻偏闷），失败自动回退原始音频。此路径同样无需你处理。

用 **tts_speak** 工具的唯一场景：需要**指定音色**或**指定情绪模式/情绪参考/向量**点播（例如"用芙宁娜的声音说……""用悲伤的语气念……"）。本轮已用工具点播时，不会再自动补发默认语音（防重复）。

## 何时用工具 / 不用

- 用：用户点名某个音色（工具描述里有音色名单）、点名情绪/语气，或要"用某人的声音说"。
- 不用：用户只是要语音回复（自动语音已覆盖）；普通问答、长报告、代码/链接（自动语音会跳过代码，但正文里保留）。


## 调用方式

```
tts_speak({
  text: "要朗读的文本",
  voice: "音色参考名",              // 省略=默认音色；可选名字见工具描述里列出的音色参考
  emotionMode: "same" | "audio" | "vector",   // 省略=配置默认
  emotionRef: "情绪参考名",          // audio 模式：情绪参考音频（可来自其他说话人）
  emotionWeight: 0.7,               // audio 模式：情绪影响强度 0~1
  vector: { happy: 0.8 },           // vector 模式：显式向量（省略=由 LLM 自动调节）
  tier: "pro" | "max",              // vector 模式的档位
  lang: "ZH"                        // 省略=配置默认
})
```

- 文本支持**多音字注音**：`<汉字|拼音+声调>`，如 `他去银<行|HANG2>取钱`、`这样很<行|XING2>`（半角 `<>|`）。
- 文本上限约 5000 字，超出请分段多次调用。
- 参考音频在 Web 面板「语音合成」上传并命名；**没有音色参考时工具会报错**，把错误如实转告用户（别编造已发送）。

## 三种情绪模式（详细）

| 模式 | 含义 | 数据要求 | 什么时候用 |
| --- | --- | --- | --- |
| `same`（Same as the voice reference） | 情绪与音色**都取自音色参考音频**——参考录音是什么语气，新台词就倾向什么语气（不会自动变平静） | 只需音色参考 | 音色参考本身就是想要的语气；或不需要情绪控制 |
| `audio`（Use emotion reference audio） | 音色取音色参考，**情绪另取一段情绪参考音频**（可以来自其他说话人）；`emotionWeight` 调节情绪参考对输出的影响强度 | 音色参考 + 情绪参考音频 | 想让 A 的声音带 B 录音里的情绪；有现成情绪录音、不想手调 |
| `vector`（Use emotion vectors） | 保留音色参考，用 **8 维向量手工/自动控制情绪**，可组合多种情绪，不需要额外录音 | 只需音色参考 | 需要精确的情绪表达；语气随文本变化（配合 max 档） |

> 模式 3「情感描述文本」当前服务支持但本插件未开放；需要"用一句话描述情绪"时，改用 vector 自动调节即可。

## 8 种情绪（vector 键名，取值 0~1.2，总和 ≤ 1.5）

| 情绪 | 键 | 典型场景 |
| --- | --- | --- |
| 高兴 | `happy` | 开心/喜悦/兴奋/得意/期待/热情夸奖 |
| 愤怒 | `angry` | 生气/斥责/抗议/被冒犯（含故作愤怒的吐槽） |
| 悲伤 | `sad` | 难过/失落/离别/同情安慰 |
| 害怕 | `afraid` | 恐惧/紧张/怯场/担心后果 |
| 厌恶 | `disgusted` | 嫌弃/反感/吐槽 |
| 忧郁 | `melancholic` | 低落/疲惫/丧/怀旧/深夜感慨 |
| 惊讶 | `surprised` | 吃惊/意外/惊喜/难以置信 |
| 平静 | `calm` | 中性陈述/日常应答/安抚；无明显情绪时用平静压底 |

取值建议：单一主导 0.6~0.95，叠加 1~2 个次要情绪 0.1~0.3；不要同时给两个以上强情绪。

## pro / max 档位（仅 vector 模式）

- **pro（默认）**：整段文本**一套情绪**、一次合成。快；适合短句、语气统一的文本。
- **max**：按文本语义**按需拆分**，每段单独设置情绪分别合成，再用 ffmpeg 拼成一条语音。更细腻；适合长文本、情绪起伏大（先平静叙述 → 突然惊讶 → 结尾温柔）。
- 两档都不需要你手填向量：**默认由 LLM 结合"要朗读的文本 + 近期对话上下文"自动判定**（只给文本会把反讽/玩笑/旁白判错，所以上下文一并提供）。你明确知道该用什么语气时，也可直接传 `vector` 覆盖。

## 失败与排查

- 报"接口地址未配置 / 连接失败"：把原文如实转告（去 Web 面板「语音合成 → IndexTTS」填地址/测试连接），不要改口说已发送。
- 报"没有可用的音色参考"：同理转告需要先上传音色参考音频。
- max 档比 pro 慢得多（每段 10~12 秒），长文本先告知用户"要合成一会儿"再调用；进度播报由框架自动处理。
