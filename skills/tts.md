# 语音合成（TTS：GPT-SoVITS / IndexTTS 2.5 / 豆包 / MiniMax / MiMo）

**总开关（默认关）**：`agent.tts.enable` 为 false（默认）时不注册 `tts_speak`、也不会自动语音。若本技能可用但 `tts_speak` 工具不在你的工具列表里，说明用户尚未开启——请让用户到 Web 面板「语音合成」开启，不要编造已发送语音。

**自动语音（开启总开关且 `autoReply` 开时生效，autoReply 默认开）**：机器人**每条最终回复都会自动追加一条语音**（文字/图片照常发送；合成内容 = 最终回复剥除 markdown/代码/链接/表格/emoji 后的正文，超长按句截断）。此路径无需你调用任何工具。

**高清语音（默认开）**：`agent.tts.hdVoice` 开启时，发送前自动做响度标准化 + 清晰度补偿（修 TTS 输出偏轻偏闷），失败自动回退原始音频。此路径同样无需你处理。

**讲稿清洗（合成入口统一）**：无论自动语音还是 `tts_speak` 点播，文本都会先剥除 markdown/代码/链接/表格/emoji，破折号（——/—/--）转为停顿（否则会被读成"减减"）；`<字|拼音>` 注音标注保留。你不需要自己清理格式。

用 **tts_speak** 工具的场景：需要**指定音色**或**指定情绪/风格**点播（例如"用芙宁娜的声音说……""用悲伤的语气念……"）。本轮已用工具点播时，不会再自动补发默认语音（防重复）。

**当前服务商由配置决定**（`agent.tts.provider`，工具描述会写明当前是哪家、参数怎么填）：
- **GPT-SoVITS**（本地 api_v2）：音色与语气由服务端配置的参考音频决定，工具只有 `text` 参数；没有音色/情绪/档位可选，不要给 voice/emotion/tier。
- **IndexTTS 2.5**（本地）：voice=参考音频名字（需先上传）；情绪有 same/audio/vector 三种模式。
- **豆包**：voice=控制台音色 ID；情绪可不填（LLM 自动判定为语音指令/情感标签），也可填固定标签（工具参数 emotion）。
- **MiniMax**：voice=系统/复刻音色 ID；情绪可不填（LLM 自动判定），也可填固定标签（emotion，如 happy/sad/…）。
- **MiMo**：voice=预置音色名（如 冰糖/Mia）；风格可不填（LLM 判定后自动生成自然语言风格指令，支持复合情绪"压抑的愤怒"、语速/发声方式、导演式、唱歌与方言点名），也可用 style 直接指定；配置 `tagMode` 开启时还会按需插入音频标签（句首 `(风格)` + 行内 `[笑]/[叹气]/[颤抖]/[语速加快]` 等，只插标签不改原文，改写的一律丢弃）。

## 何时用工具 / 不用

- 用：用户点名某个音色（工具描述里有音色名单）、点名情绪/语气，或要"用某人的声音说"。
- 不用：用户只是要语音回复（自动语音已覆盖）；普通问答、长报告、代码/链接（自动语音会跳过代码，但正文里保留）。


## 调用方式（IndexTTS 服务商示例）

```
tts_speak({
  text: "要朗读的文本",
  voice: "音色参考名",              // 省略=默认音色；可选名字见工具描述里列出的音色参考
  emotionMode: "same" | "audio" | "vector",   // 省略=配置默认（仅 IndexTTS）
  emotionRef: "情绪参考名",          // audio 模式：情绪参考音频（可来自其他说话人）
  emotionWeight: 0.7,               // audio 模式：情绪影响强度 0~1
  vector: { happy: 0.8 },           // vector 模式：显式向量（省略=由 LLM 自动调节）
  tier: "pro" | "max",              // 档位
  lang: "ZH"                        // 省略=配置默认
})
```

GPT-SoVITS 示例：`tts_speak({ text: "要朗读的文本" })`——只有 text 参数，音色/语气由服务端参考音频决定，不要传 voice/emotion/tier。

云服务商示例：`tts_speak({ text, voice: "音色ID/名", emotion: "happy" | 省略, tier })`（MiMo 用 `style` 代替 `emotion`）。参数以工具实际描述为准，不要照搬 IndexTTS 专属参数。

- 文本支持**多音字注音**：`<汉字|拼音+声调>`，如 `他去银<行|HANG2>取钱`、`这样很<行|XING2>`（半角 `<>|`）。
- 文本上限约 5000 字，超出请分段多次调用。
- IndexTTS 的参考音频在 Web 面板「语音合成」上传并命名；**没有音色参考时工具会报错**，把错误如实转告用户（别编造已发送）。GPT-SoVITS 的参考音频是服务端本地路径，由用户在面板配置；云服务商则是音色 ID/名称未配置时报错，同理。

## 三种情绪模式（详细，仅 IndexTTS 服务商）

| 模式 | 含义 | 数据要求 | 什么时候用 |
| --- | --- | --- | --- |
| `same`（Same as the voice reference） | 情绪与音色**都取自音色参考音频**——参考录音是什么语气，新台词就倾向什么语气（不会自动变平静） | 只需音色参考 | 音色参考本身就是想要的语气；或不需要情绪控制 |
| `audio`（Use emotion reference audio） | 音色取音色参考，**情绪另取一段情绪参考音频**（可以来自其他说话人）；`emotionWeight` 调节情绪参考对输出的影响强度 | 音色参考 + 情绪参考音频 | 想让 A 的声音带 B 录音里的情绪；有现成情绪录音、不想手调 |
| `vector`（Use emotion vectors） | 保留音色参考，用 **8 维向量手工/自动控制情绪**，可组合多种情绪，不需要额外录音 | 只需音色参考 | 需要精确的情绪表达；语气随文本变化（配合 max 档） |

> 模式 3「情感描述文本」当前服务支持但本插件未开放；需要"用一句话描述情绪"时，改用 vector 自动调节即可。

## 8 种情绪（vector 键名，取值 0~1.2，总和 ≤ 1.5）

| 情绪 | 键 | 典型场景 |
| --- | --- | --- |
| 高兴 | `happy` | 开心/喜悦/兴奋/得意/期待/热情夸奖 |
| 愤怒 | `angry` | 生气/斥责/抗议/被冒犯（含故作愤怒的吐槽） |
| 悲伤 | `sad` | 难过/失落/离别/同情安慰 |
| 害怕 | `afraid` | 恐惧/紧张/怯场/担心后果 |
| 厌恶 | `disgusted` | 嫌弃/反感/吐槽 |
| 忧郁 | `melancholic` | 低落/疲惫/丧/怀旧/深夜感慨 |
| 惊讶 | `surprised` | 吃惊/意外/惊喜/难以置信 |
| 平静 | `calm` | 中性陈述/日常应答/安抚；无明显情绪时用平静压底 |

取值建议：单一主导 0.6~0.95，叠加 1~2 个次要情绪 0.1~0.3；不要同时给两个以上强情绪。

**IndexTTS/豆包/MiniMax/MiMo 四家共用这套 8 维判定**（由 LLM 结合文本+上下文自动出向量）：IndexTTS 直接用向量；豆包 1.0 映射为情感标签+强度、豆包 2.0 映射为语音指令；MiniMax 映射为 9 标签之一（忧郁→sad）；MiMo 映射为自然语言风格指令。所以这几家同样"不用手填情绪"，除非你明确要指定。**GPT-SoVITS 没有情绪参数**，不参与判定，情绪完全由参考音频决定。

## pro / max 档位

- **pro（默认）**：整段文本**一套情绪**、一次合成。快；适合短句、语气统一的文本。
- **max**：按文本语义**按需拆分**，每段单独判定/设置情绪分别合成，再用 ffmpeg 拼成一条语音。更细腻；适合长文本、情绪起伏大（先平静叙述 → 突然惊讶 → 结尾温柔）。
- IndexTTS 仅 vector 模式有档位；云服务商（豆包/MiniMax/MiMo）pro/max 都可用（max 会为每段单独调用一次合成接口，更慢也更费额度）。GPT-SoVITS 没有档位，始终一次请求、由服务端切段。
- 两档都不需要你手填向量：**默认由 LLM 结合"要朗读的文本 + 近期对话上下文"自动判定**（只给文本会把反讽/玩笑/旁白判错，所以上下文一并提供）。你明确知道该用什么语气时，也可直接传 `vector`（或云服务商的 emotion/style）覆盖。

## 失败与排查

- 报"接口地址未配置 / 连接失败"：把原文如实转告（去 Web 面板「语音合成 → 对应服务商」填地址/密钥后「测试连接」），不要改口说已发送。云服务商测试会真实合成 2 个字。
- 报"没有可用的音色参考"（IndexTTS）：转告需要先上传音色参考音频；报"参考音频路径未配置"（GPT-SoVITS）：转告去面板对应服务商填服务端本地绝对路径与参考文本；报"音色 ID/API Key 未配置"（云服务商）：转告去面板对应服务商卡片补全。
- 报限流/鉴权失败：把错误里的提示如实转告（Key 无效、RPM/TPM 超限、欠费未开通等），不要重试轰炸。
- max 档比 pro 慢得多（云端每段一次请求；IndexTTS 每段约 10~12 秒），长文本先告知用户"要合成一会儿"再调用；进度播报由框架自动处理。
